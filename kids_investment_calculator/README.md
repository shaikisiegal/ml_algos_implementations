# קופת הילדים – מחשבון השקעה לילדים

מחשבון אינטראקטיבי (קובץ HTML יחיד) לתכנון השקעה משותפת לכמה ילדים בגילים שונים.

- סכום חד־פעמי כולל + הפקדה חודשית כוללת
- גיל יעד (או מספר שנים משותף) וסכום יעד לכל ילד
- מסלולי השקעה עם תשואה ודמי ניהול, מסלול לכל ילד
- ארבע אסטרטגיות חלוקה, שלוש מהן מאזנות כך שכל ילד מגיע ליעד עם אותו סכום
- מס רווח הון ואינפלציה (כולל איזון בכוח קנייה)
- גרפים: צמיחה לאורך זמן, פירוק הפקדות/רווח/מס, טבלת רגישות לתשואה, וכמה צריך כדי להגיע ליעד

פתחו את `index.html` בדפדפן.
